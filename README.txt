ATLAS Research Portfolio Website

Files:
- index.html: page structure and Statement of Purpose content
- styles.css: responsive visual design and print styles
- script.js: mobile navigation, SOP accordion, print/PDF action, reading progress

Preview:
Open index.html in a modern browser.

Before publishing:
1. Open script.js.
2. Replace PROFILE.linkedin with your actual LinkedIn profile URL.
3. Replace PROFILE.email with the email address you want displayed.
4. Review the faculty, publication, degree, and date references for accuracy.
5. Publish the folder using a static host such as GitHub Pages, Netlify, or your own web hosting.

The website is a static site and does not require a backend or build process.
